### 3.1 UI-SPLASH-V0 + UI-HOME-V0

- Splash и Home **обязательно** показывают «БашЛегенды: Эпоха Абсурда».
- Full-bleed намёк на L01 на Home.

- Витрина: Каэрон.
- См. композицию в DESIGN_SYSTEM §7.

### 3.2 L01 + ARENA-L01

- День, crisis props умеренно.
- Слои sky/far/mid/props/near/fx.
- Арена с полом и UI-safe зонами.
- См. LOCATION_STYLE_GUIDE §8.

### 3.3 H01–H03 + E01

- Концепт + UI portrait + **static dialog bust** + Blender→2D atlas (или помеченный placeholder до bake).
- Классовые цвета и описания строго HEROES.md.
- См. CHARACTER_STYLE_GUIDE §5–§7.

### 3.4 Критерии приёмки V0

1. Единая палитра и стиль Premium Clean Stylized Fantasy 2.5D.
2. 9:16 читаемость на ширине ≥360 px.
3. Силуэты H01–H03 и E01 различимы.
4. Сатира в талонах/терминале, не в «уродливом» UI.
5. ID совпадают с HEROES/CAMPAIGN.
6. Ни один файл не назван «финальным ассетом игры» без review.
7. Механики GDD не изменены.
8. Название на splash/home; диалоги со статичными портретами; runtime без 3D-персонажей.
