## 3. Вертикальный срез V0 — детальный бриф

### 3.1 UI-HOME-V0

- Full-bleed намёк на L01.
- Wordmark рабочего названия **только если утверждено** к показу; иначе нейтральный «Campaign» placeholder brand mark.
- CTA: В кампанию; AFK chip.
- Витрина: Каэрон.
- См. композицию в DESIGN_SYSTEM §7.

### 3.2 L01 + ARENA-L01

- День, crisis props умеренно.
- Слои sky/far/mid/props/near/fx.
- Арена с полом и UI-safe зонами.
- См. LOCATION_STYLE_GUIDE §8.

### 3.3 H01–H03 + E01

- Концепт + портрет + боевой (или помеченный placeholder).
- Классовые цвета и описания строго HEROES.md.
- См. CHARACTER_STYLE_GUIDE §5–§7.

### 3.4 Критерии приёмки V0

1. Единая палитра и стиль Premium Clean Stylized Fantasy 2.5D.
2. 9:16 читаемость на ширине ≥360 px.
3. Силуэты H01–H03 и E01 различимы.
4. Сатира в талонах/терминале, не в «уродливом» UI.
5. ID совпадают с HEROES/CAMPAIGN.
6. Ни один файл не назван «финальным ассетом игры» без review.
7. Механики GDD не изменены.

### 7.4 Риски / расхождения для внимания владельца

1. **HEROES.md** помечает конкретных героев как *предложения* на согласование; визуал V0 строится на H01–H03 — утвердить состав до генерации.
2. **CAMPAIGN_LOCATIONS** — сценарный пакет v1.0, «не утверждён по отдельности»; L01 как срез ок как рабочий прототип.
3. GDD §8: точные имена/главы открыты — визуальные доки не должны читаться как замена утверждению контента.
4. ROAD следующий шаг всё ещё включает Phase 0 инженерии (API/аудит кода); визуальный пакет **параллелит** детализацию этапа 04, не закрывает этап 01–15 как ГОТОВО.
5. Редкость Mythic градиент — декоративен; Mythic героев в стартовых 12 нет.

### 7.5 Вердикт аудита

**Документы визуала согласованы между собой и не противоречат утверждённым механикам GDD/ROAD.**  
Контентные имена героев и главы остаются в статусе «проект/на согласование» согласно исходным файлам.  
**Ассеты не произведены** — готовность визуала = спецификация, не `ГОТОВО` по ROAD.
