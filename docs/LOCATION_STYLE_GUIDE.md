# LOCATION_STYLE_GUIDE.md — Локации, карта, арены

> Версия: 1.0 · 2026-11-19 · Статус: **проект для согласования**
> Источники: WORLD-*, CAMPAIGN_LOCATIONS.md (CH01), ART_DIRECTION.md
> География реальна как прототип; учреждения и злодейства — вымышленные.

## 0. Принципы

1. Узнаваемость прототипа через силуэт горизонта / рельефа / промышленного профиля — не через чужие логотипы.
2. Локация = многослойный 2D/2.5D фон + отдельная боевая сцена + точки интереса.
3. Свободного 3D-передвижения нет (CAMPAIGN § карточки локаций).
4. Сатира — в props (талоны, знаки, бланки), не в «сломанной» перспективе.
5. День/ночь — там, где сюжетно нужно; CH01 V0 — дневная L01.

## 1. Иерархия пространства

```
Республика (карта 2D)
  → Город (якорь на карте)
    → Район / сюжетная зона
      → Локация Lxx (интерактивная сцена)
        → Боевая арена ARENA-Lxx
```

## 2. Слои локационной сцены

| Слой | Имя | Содержание | Параллакс |
|---|---|---|---|
| 0 | `sky` | Небо, дальнее свечение | 0.1 |
| 1 | `far` | Силуэт города / гор | 0.25 |
| 2 | `mid` | Основные здания, площадь | 0.5 |
| 3 | `props` | Интерактивы, терминалы, знаки | 0.75 |
| 4 | `near` | Передний план, бордюр, бумага | 1.0 |
| 5 | `fx` | Магические частицы, штампы | 1.0 + additive |

Боевая арена использует те же mid/far, но расчищенный `battle_floor` и безопасные зоны под UI ультимейтов.

## 4. Правила зданий и природы

### Здания

- Чистые объёмы, крупные окна-витражи с магией, мягкие тени.
- Этажность читается пятнами, не сотней мелких окон.
- Вывески и штампы — стилизованные руны/пиктограммы, не копирайт чужих марок.

### Природа

- Хвоя и склоны — shape language крупными массами.
- Облака и туман — мягкие градиенты + 1–2 облачных спрайта.
- Вода/река — stylized sheets, не фото-вода.

### Props сатиры (лимит)

На одной сцене ≤ 5 заметных комических props, иначе визуальный шум. Пример L01: терминал, рой талонов, указатель очереди, печать в небе, барьер.

## 5. Боевые арены

| Правило | Описание |
|---|---|
| Пол | Плоская читаемая зона под 5 героев + врагов |
| Линии | Передняя / задняя размечены мягко (не сетка Excel) |
| UI-safe | Нижние 22% и верхние 12% без критичного арта |
| VFX budget | Low: 0–1 emitter; Med: 2–3; High: до 5 локальных |
| Камера | Фиксированный портретный кадр; лёгкий shake только на ультимейтах High |

## 6. Состояния локации по сюжету

Для каждой Lxx предусмотреть флаги (данные, не обязательно отдельные PSD):

| Состояние | Пример L01 |
|---|---|
| `default` | Дневная площадь |
| `quest_active` | Подсветка терминала / квестовый маркер |
| `crisis` | Барьеры, рой талонов (после Q01) |
| `cleared` | Спокойнее FX, открытый проход |
| `night` (опц.) | Emissive терминалов |

## 8. Вертикальный срез: L01 + ARENA-L01

### L01 — Центр Уфы — Площадь талонов (день)

- **Узнаваемость:** широкая городская площадь + современный силуэт админ-зданий, переработанных в магические башни со светящимися печатями.
- **Доминанта:** центральный магический терминал.
- **Сатира:** рой талонов с номерами, указатель «Очередь 800 лет».
- **Интерактивы:** терминалы, барьеры, указатели (CAMPAIGN).
- **Приёмка:** открытие, переходы, сохранение сцен, 9:16.

### ARENA-L01

- Тот же mid/far, затемнённый near.
- Боевой пол из плитки площади с магическим кругом.
- Место под E01 «Живой талон».
