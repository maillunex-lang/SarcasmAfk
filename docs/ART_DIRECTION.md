> Версия: 1.0 · 2026-11-19 · Статус: **проект для согласования**
> Рабочее название: **БашЛегенды: Эпоха Абсурда** · Internal ID: `BashLegends`
> Источники: `GDD.md`, `ROAD.md`, `HEROES.md`, `CAMPAIGN_LOCATIONS.md`
> Не является готовыми ассетами. Не меняет утверждённые механики VIS/HERO/STORY/TECH.

## 0. Назначение и границы

- Зафиксировать единый визуальный язык для героев, врагов, локаций, карты, UI и VFX.
- Согласовать стиль **Premium Clean Stylized Fantasy 2.5D** с решениями VIS-001 C / VIS-002 C / VIS-003 A.
- Подготовить проверяемый вертикальный срез (см. §8), а не массовую генерацию ассетов.
- Юмор — в сценарии, врагах и деталях окружения; визуал остаётся премиальным и чистым.
- Рабочее название не переименовывает репозиторий `SarcasmAfk` и Android package ID без отдельного подтверждения.

## 1. Позиционирование стиля

| Параметр | Решение |
|---|---|
| Стиль | Premium Clean Stylized Fantasy 2.5D |
| База персонажей | Stylized Anime Fantasy, умеренно мультяшные пропорции |
| Мир | Художественно переработанный Башкортостан + магия + современность |
| Тон картинки | Ярко, гармонично, «дорого», без фотореализма |
| Тон сатиры | В деталях, вывесках, врагах, пропах; не в «уродливом» UI |
| Ориентация | Строго 9:16, touch-first |
| Платформа | Android, минимум 6 ГБ ОЗУ; пресеты Low / Medium / High |

### Что стиль делает

- Читаемые силуэты на маленьком экране.
- Единый язык цвета, материалов и освещения.
- Узнаваемые города без копирования реальных логотипов и госорганизаций.
- Красивые магические эффекты, оптимизированные под мобильные пресеты.

### Что стиль запрещает

- Фотореализм, грязные PBR-текстуры, «AAA-грязь».
- Чрезмерно мелкий орнамент, нечитаемый в портрете 9:16.
- Тяжёлые полноценные 3D-сцены там, где достаточно многослойного 2D.
- Карточный UI с перегруженными рамками и неоновыми glow-стеками.
- Переименование утверждённых героев H01–H12 и смену классов/редкостей без согласования.

## 2. Визуальный питч (one-liner)

**«Чистый аниме-фэнтези Башкортостан: магические города, бюрократический абсурд в деталях, премиальный мобильный UI и AFK-бои с выразительными героями.»**

## 3. Столпы визуала

1. **Силуэт прежде деталей** — герой и враг узнаются за 0.3 с.
2. **Глубина слоями** — локации = far / mid / near / FX, не один плоский JPEG.
3. **Цветовая иерархия** — золото = ценность/CTA, cyan = магия/система, coral = угроза.
4. **Сатира в props** — талоны, штампы, знаки, бланки; не в «ломаном» рендере.
5. **Производительность как стиль** — красота, которую можно урезать пресетами без потери читаемости.

## 4. Соответствие утверждённым VIS-решениям

| ID | Утверждено | Как отражено в арт-дирекции |
|---|---|---|
| VIS-001 C | Гибрид скелетной 2D и атласов | Герои/враги: Spine/Godot Skeleton2D или bake из 3D → атлас |
| VIS-002 C | Cartoon Fantasy + современный UI | Stylized Anime Fantasy + Premium Fantasy Mobile UI |
| VIS-003 A | Вертикальный 9:16 | Все макеты и промпты — портрет; safe area под вырезы |

Уточнение относительно GDD CONCEPT-005 E («Cartoon + Fantasy + 2.5D»): текущий документ детализирует его как **Premium Clean Stylized Fantasy 2.5D** без смены утверждённого кода решения.

Базовая палитра UI (канон `DESIGN_SYSTEM.md`):

| Имя | Hex | Роль |
|---|---|---|

| Royal Gold | `#E8BC68` | CTA, награды, редкость SSR+ акцент |
| Arcane Cyan | `#54D9DA` | Магия, система, AFK, прогресс |
| Soft Ivory | `#F5F0E5` | Основной текст на тёмном, пергамент |
| Danger Coral | `#E86D70` | Урон, ошибки, опасные зоны |

Освещение мира: мягкий ключ + тёплый rim на героях; холодный cyan на магических артефактах; ночные состояния — понижение экспозиции и усиление emissive, не «чёрный экран».

## 6. Классовая цветовая идентификация героев

| Класс | Акцент | Материал-якорь |
|---|---|---|
| Танк | Графит + малахит / медь | Металл, камень, щит |
| Воин | Янтарь + тёмно-синий | Клинок, плащ, динамика |
| Маг | Лиловый / лазурь + cyan | Руны, кристаллы, свитки |
| Поддержка | Бирюза / кремовый / мягкое золото | Инструменты, фонари, печати лечения |

Редкости влияют на орнамент рамки и плотность VFX, **не** на смену силуэта класса.

## 7. Сатира без ущерба премиум-виду

| Можно | Нельзя |
|---|---|
| Ожившие талоны, штампы, бланки как враги | Карикатурный «уродливый» UI |
| Вывески-абсурд, очереди, формы 404-Б | Реальные логотипы ведомств |
| Комик-пропсы в фоне локации | Оскорбительные изображения реальных людей |
| Юмор в диалогах и именах врагов | Визуальный хаос, ломающий читаемость боя |

## 8. Вертикальный срез V0 (проверяемый)

Цель: один согласованный пакет для утверждения стиля **до** массовой генерации.

| Элемент | ID / содержание |
|---|---|
| Главный экран | `UI-HOME-V0` — оболочка 9:16, CTA «Кампания», AFK-кнопка, слот героя |
| Локация | `L01` Центр Уфы — Площадь талонов (день) |
| Боевая арена | `ARENA-L01` — слои площади + зона боя |
| Герои | `H01` Каэрон, `H02` Вейриса, `H03` Эльдарион |
| Враг-эталон | `E01` Живой талон |
| Диалог | Окно CH01-Q01 без обязательного портрета |

Критерии приёмки среза: единая палитра, читаемость на 360×640 логических px, силуэты различимы, сатира только в props/враге, документы не противоречат GDD/HEROES/CAMPAIGN.

Подробные промпты и чеклисты — в `VISUAL_ROADMAP.md` § Vertical Slice и `ASSET_PIPELINE.md`.
