# AFK MMORPG демо — Flutter + Flame

Вертикальное 2.5D AFK-демо в духе Diablo: маг vs волк.

## Возможности

- Автобой (AFK)
- Герой: бег, **ледяная сосулька**, ультимейт **огненный шар** (искры + взрыв)
- Волк: бег / укус
- HUD: HP, таймер, кнопки ULT / ×2 / Меню

## Запуск

```bash
export PATH="$HOME/flutter-sdk/flutter/bin:$PATH"
cd flutter_afk_mmorpg
flutter pub get
flutter run -d chrome
```
